# AstraTrade AI Phase 4 产品 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品 | AstraTrade AI 多用户模拟交易控制台 |
| 阶段 | Phase 4：产品体验扩展 |
| 状态 | 待评审 |
| 基线 | `main` 已包含多用户、模拟 Agent、净值曲线、风控审计和 OAuth 测试连接 |
| 目标用户 | 受邀请码邀请的内部测试用户、管理员 |

## 2. 背景与问题

当前版本已经能够完成模拟定投，但用户仍需要在多个页面之间拼接信息，才能理解一次执行的原因、手续费和账户变化。管理员也只能管理邀请码，缺少运行概览。

Phase 4 的目标不是扩大交易风险，而是提升模拟结果的可解释性、可操作性和测试反馈质量。

## 3. 阶段目标

用户能够独立完成一次模拟定投，并准确理解：

1. Agent 为什么执行或没有执行；
2. 账户余额、BTC 持仓和净值如何变化；
3. 模拟手续费如何计算；
4. 风控拦截的具体原因；
5. 如何导出自己的测试数据。

## 4. 范围

### 4.1 本阶段包含

- 模拟账户分析：净值、收益、手续费、持仓变化；
- 模拟订单详情；
- 定投策略模板；
- 站内通知；
- 用户数据导出；
- 管理员只读运行概览。

### 4.2 明确不包含

- 真实资金、真实下单、资产划转；
- 手动下单；
- 合约、杠杆、借贷、做空；
- 多策略同时运行；
- 自动调整仓位或自动复投收益；
- 公开注册和无邀请码注册；
- 生产 OAuth Provider 的启用。

## 5. 用户故事与需求

### 5.1 模拟账户分析

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| P4-AN-01 | 用户查看净值走势 | 支持 7 日、30 日和全部记录；无数据时有明确空状态 |
| P4-AN-02 | 用户查看收益拆分 | 页面分别展示持仓估值变化、手续费和累计盈亏 |
| P4-AN-03 | 用户查看账户变化 | 每个时间点至少展示现金、BTC、参考价、净值和盈亏 |
| P4-AN-04 | 用户理解模拟口径 | 页面持续标注“模拟交易”，并说明手续费固定按 0.1% 计算 |

### 5.2 模拟订单详情

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| P4-OD-01 | 查看订单详情 | 从订单列表进入详情页或抽屉 |
| P4-OD-02 | 查看执行原因 | 显示 Agent 配置、执行频率、预算和触发时间 |
| P4-OD-03 | 查看执行结果 | 显示价格、数量、名义金额、手续费和执行后余额 |
| P4-OD-04 | 查看风控链路 | 显示检查通过或拦截的结果，不展示内部密钥 |

### 5.3 定投策略模板

首批模板：

| 模板 | 预算 | 频率 | 用途 |
| --- | ---: | --- | --- |
| 小额试运行 | 20 USDT | 每周 | 首次体验 |
| 保守定投 | 100 USDT | 每周 | 默认推荐 |
| 高频小额 | 100 USDT | 每日 | 观察频繁执行 |
| 自定义 | 1–500 USDT | 每日/每周 | 熟悉用户 |

模板必须允许用户在服务端限制内调整，但不能绕过预算上限。

### 5.4 站内通知

通知类型：Agent 启动、订单成交、风控拦截、行情失效、执行失败、Agent 停止。

要求：

- 展示未读数；
- 支持全部标记已读；
- 支持按类型筛选；
- 点击通知可跳转到相关页面；
- 通知生成必须幂等，重复调度不能生成重复通知。

### 5.5 用户数据导出

支持导出当前用户自己的订单、净值历史和审计记录。格式为 CSV；Agent 配置可导出 JSON。所有导出内容必须标注模拟数据，不得包含密码、Session、OAuth Token 或内部路径。

### 5.6 管理员运行概览

管理员只读查看：用户数、活跃 Agent 数、执行次数、成交数、风控拦截数、行情失败数和最近错误。

管理员不得代替用户启动 Agent、修改模拟余额或查看用户敏感凭据。

## 6. 成功指标

- 新用户完成首次模拟执行的比例 ≥ 80%；
- 首次执行后能查看订单详情的比例 ≥ 90%；
- 风控拦截页面的原因理解正确率 ≥ 80%；
- 导出文件成功率 ≥ 99%；
- 重复调度不产生重复订单或重复通知；
- 测试期间无跨用户数据暴露。

## 7. 发布策略

1. 先在测试环境对管理员和内部测试用户开放；
2. 收集至少 3 名测试用户反馈；
3. 通过验收剧本后再扩大邀请码发放；
4. 本阶段不启用真实交易 Provider。

## 8. 评审决策点

- 是否接受首批四个策略模板；
- 是否首期只做 CSV/JSON 导出；
- 站内通知是否足够，是否需要邮件通知；
- 管理员概览是否允许查看用户级聚合数据；
- 是否维持单 Agent、单标的限制。
