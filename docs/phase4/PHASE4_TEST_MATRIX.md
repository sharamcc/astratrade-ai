# AstraTrade AI Phase 4 测试矩阵与试用准备

## 1. 测试账号

| 账号 | 用途 | 数据边界 |
| --- | --- | --- |
| 管理员 | 创建/停用邀请码、查看聚合概览 | 不读取普通用户订单详情 |
| 用户 A | 完成主流程 | 只能访问自己的模拟数据 |
| 用户 B | 验证隔离 | 不能读取用户 A 的任何导出或订单 |
| 未登录会话 | 验证认证边界 | 只能访问登录、注册和健康检查 |

## 2. 场景矩阵

| 场景 | 输入/动作 | 关键断言 | 证据 |
| --- | --- | --- | --- |
| 正常主流程 | 注册、配置、启动、查看订单、停止 | 余额、手续费、通知和审计一致 | 页面快照 + API 响应 |
| 邀请码失败 | 无效、耗尽、停用邀请码 | 注册拒绝且不创建账户 | 响应码 + 数据库计数 |
| 风控拦截 | 余额不足或预算超限 | 无订单、无扣款、有原因和通知 | Dashboard + Audit |
| 行情失效 | 价格为空、过期或请求失败 | 跳过执行并记录原因 | Audit + Admin 概览 |
| 隔离 | B 请求 A 的订单/导出 | 返回无权限或不存在 | API 响应 |
| 会话安全 | 缺 CSRF、旧会话、未登录写请求 | 拒绝写入 | 响应码 + 数据未变化 |
| 导出 | 三类 CSV 和 Agent JSON | 文件可读、不含密钥、只含本人数据 | 下载文件内容 |
| 移动端 | 关键路径在窄视口执行 | 可查看、启动和停止 | 浏览器快照 |

## 3. 试用前检查

- 数据库备份任务和最近备份文件可见；
- API、Worker 和 HTTPS 均为 active/healthy；
- 测试服管理员密码已修改并安全保存；
- 当前数据库不包含历史测试用户、订单或 OAuth 连接；
- 回滚版本与对应数据库备份已记录；
- 测试用户只获得模拟交易权限，不提供真实资金能力。

## 4. 通过标准

- E2E-01 至 E2E-08 全部通过；
- SEC-01 至 SEC-06 全部通过；
- 桌面端与移动端关键路径通过；
- 无 P0/P1 未关闭问题；
- 至少三名内部用户完成主流程并提交反馈。
