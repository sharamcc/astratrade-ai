# AstraTrade AI Strategy V2 验收测试计划

## 1. 测试范围

覆盖策略基础层、均线策略、网格策略、组合定投、服务端风控、账本幂等、多用户隔离、前端交互和部署恢复。

所有测试均使用模拟账户和公开/测试行情，不发送真实订单。

## 2. 测试角色与数据

- 管理员：创建邀请码、查看聚合概览；
- 用户 A：执行均线策略；
- 用户 B：执行网格策略；
- 用户 C：执行组合定投；
- 未登录会话：验证认证边界。

每个用户初始获得 10,000 USDT 模拟余额。测试前记录数据库备份、发布版本、行情固定值和测试时间。

## 3. 单元测试

### STR-U01 策略配置校验

- 不支持的策略类型被拒绝；
- 缺少必填参数被拒绝；
- 预算、比例、区间和周期超过服务端限制被拒绝；
- 合法配置生成不可变版本。

### STR-U02 均线信号

- 金叉只产生买入信号；
- 死叉只产生卖出信号；
- 无交叉时产生 hold/skip；
- 相同窗口和行情输入得到相同信号。

### STR-U03 网格信号

- 价格触及下格生成买入信号；
- 价格触及上格生成卖出信号；
- 区间外暂停新信号；
- 网格重算产生新版本，不复用旧执行键。

### STR-U04 组合分配

- 固定金额和比例分配结果正确；
- 比例总和不为 100% 时拒绝；
- 单标的失败不会改变其他标的账本；
- 组合总额不会超过预算上限。

### STR-U05 风控与账本

- 余额不足、价格过期、冷却中和重复信号均被拦截；
- 允许执行的手续费按 0.1% 计算；
- 相同执行键只能生成一笔订单；
- 风控拒绝不扣余额、不生成成交订单。

## 4. API 集成测试

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| STR-A01 | 用户创建均线策略 | 返回策略 ID 和版本 |
| STR-A02 | 用户更新已运行策略 | 创建新版本，不覆盖历史执行 |
| STR-A03 | 用户启动/停止策略 | 状态和下一次执行时间正确 |

| STR-A08 | 组合行情部分失败 | 其他标的仍按独立结果处理 |

| STR-A10 | 导出策略执行记录 | 只返回当前用户数据 |

## 5. 浏览器端 E2E

### E2E-S01 均线策略

1. 用户 A 登录；
2. 创建均线策略并保存参数；
3. 启动策略；
4. 查看当前均线、信号、订单详情和净值；
5. 停止策略。

预期：信号原因、风控结果、手续费、账户变化和审计事件均可见。

### E2E-S02 网格策略

1. 用户 B 创建价格区间和网格数量；
2. 使用固定行情触发一个下格和一个上格；
3. 将价格置于区间外；
4. 查看暂停通知；
5. 停止并重新启动策略。

预期：每格最多执行一次，区间外不生成新订单，重启不会重复成交。

### E2E-S03 组合定投

1. 用户 C 配置两个模拟标的和分配比例；
2. 启动组合策略；
3. 让一个标的行情失效；
4. 查看组合执行详情、持仓和手续费；
5. 导出组合执行记录。

预期：失败标的不影响其他标的，组合总预算正确，导出不含敏感信息。

## 6. 安全与隔离

- 用户 A 不能读取 B/C 的策略、信号、订单或导出；
- 管理员只能查看聚合概览，不能默认读取用户级详情；
- 未登录不能访问策略和模拟账户 API；
- CSRF、来源、限流和会话失效规则继续有效；
- 页面和日志不能出现密码、Session、Token 或私有密钥。

## 7. 前端与移动端

- 桌面端验证策略列表、配置、信号详情、订单详情、通知和导出；
- `390×844` 窄视口验证查看、启动和停止策略；
- 验证加载、空数据、行情失败、风控拒绝、401、403 和 429 状态；
- 保存、启动、停止按钮在请求期间不可重复提交；
- 刷新后策略状态、版本和通知已读状态保持一致。

## 8. 非功能与部署

- 后端、前端、构建和依赖审计通过；
- 数据库迁移可重复执行；
- API/Worker 重启后可恢复；
- 发布前 SQLite 备份可读取并能恢复到临时实例；
- HTTP/HTTPS、Cookie 安全属性和健康检查通过；
- 监控日志无敏感信息。

## 9. 发布门槛

1. STR-U01 至 STR-U05 全部通过；
2. STR-A01 至 STR-A10 全部通过；
3. E2E-S01 至 E2E-S03 全部通过；
4. 安全与数据隔离测试全部通过；
5. 三名内部用户分别完成已发布策略的主流程；
6. 无 P0/P1 缺陷；
7. 产品、开发和安全评审确认后，才扩大测试范围。
