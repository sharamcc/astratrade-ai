## 3. 结果核对

- 用户 A：1 笔模拟订单，均线金叉信号状态为 `filled`。
- 用户 B：1 笔模拟订单；区间外未新增订单，并生成 `strategy_paused_out_of_range` 通知。
- 用户 C：3 笔模拟订单，包含 BTC-USDT 与 ETH-USDT；4 个信号中 3 个成交、1 个因行情缺失跳过。
- 用户 C 绩效接口返回 BTC/ETH 独立持仓、最近行情和持仓估值。
- 组合手续费累计 `0.17000000 USDT`，按模拟费率 0.1% 计算。
- 用户 A 读取用户 B 策略返回 `404`；读取用户 C 绩效返回 `404`。
- 缺少 CSRF 的停止请求返回 `403`，数据未改变。
- 用户 C 的策略导出仅包含 C 的策略信号，不包含其他用户策略 ID。
- 管理员概览接口可访问，普通用户权限隔离保持有效。

## 6. 缺陷处理

验收过程中发现并修复了旧数据库兼容问题：

1. 旧 `risk_decisions` 表字段约束导致新策略写入失败；
2. 旧 `risk_decisions.signal_id` 外键指向旧版 `signals` 表，不能承载 Strategy V2 信号。

最终方案新增 `strategy_risk_decisions`，保留旧仓储风控表不变，并已通过旧表结构回归测试。
